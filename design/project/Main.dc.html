Limits that actually hold

Position size, leverage, daily loss and a symbol allowlist, checked before anything reaches the exchange. There is no tool that changes them, so the model cannot talk its way past them.

Paper trade on real prices

Orders walk real book depth and pay real fees, so the curve is honest about slippage. Same tools, same limits, same agent — the only difference is that the fills are simulated.

Every decision on the record

Each order is stored with the reason the agent gave for it — including the ones the limits refused. When something strange happens at 3am, you can read exactly what it thought it was doing.

Why Hyperliquid

Hyperliquid has paid third-party builders over $40M through builder codes, and roughly 40% of its daily active traders arrive through apps like this one. Reins routes your agent's orders there and never touches your funds.
