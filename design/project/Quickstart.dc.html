Quickstart

Paper mode is the default. You will not spend anything until you deliberately change two settings.

1

Add it to your MCP client

"reins": {
  "command": "node",
  "args": ["dist/bin/serve.js"],
  "env": {
    "REINS_SYMBOLS": "BTC,ETH",
    "REINS_MAX_POSITION_USD": "5000",
    "REINS_DAILY_LOSS_USD": "500",
    "REINS_LOG_FILE": "./decisions.jsonl"
  }
}

The three limit variables are required. There is no default for how much of your money this may lose.

2

When you are ready for real money

REINS_MODE=live
REINS_NETWORK=mainnet
REINS_PRIVATE_KEY=0x…

Two deliberate changes, not one forgotten variable. Live without a key stays read-only rather than failing on your first order.

Nine tools

Everything that can move money is risk-checked and logged first.

place_order
Sized in USD, with a required reason
close_position
Reduce-only, allowed even when halted
cancel_order
By exchange order id
set_stop_loss
A stop the exchange holds, even while the agent sleeps
get_limits
Headroom, loss budget, halted state
get_positions
Exposure, equity, today's realised PnL
get_book
Depth, spread, nearest levels
get_candles
Price history, 1m to 1d, forming candle flagged
get_recent_decisions
What it already did, after a restart

There is deliberately no tool that changes the limits. The agent can read them; only you can set them.
