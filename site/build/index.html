The evidence

Reins is mine, built in public. It is not a demo: it is installed with one command, it signs real orders on Hyperliquid, and every claim below can be checked from the repository.

ShippedOn npm, PyPI and the official MCP registry. Listed and scored A on Glama.
Tested445 tests, no network needed. Twelve checks against a funded mainnet account for the parts tests cannot prove.
Three front doorsAn MCP server for Claude, Claude Code and Cursor; an HTTP API for bots in any language; a Python client with no dependencies.
Honest about resultsI let Claude trade on paper for five days and published what happened: it lost $21, of which $20 was fees. The losing runs are on the site, not buried.

That last line is the part worth hiring for. Anyone can show you a demo that worked. The useful question is what someone does with the run that did not, and whether the numbers survive being checked.
